# First procedural noise modules

The isolated `horizon/native-core` crate now implements the Java scalar/hash helpers, all 296 literal gradient/cell vectors, Perlin static/fractal sampling and Simplex static/fractal sampling. It has no external Cargo dependencies, forbids unsafe code, and is not active in the prepared-terrain pipeline.

The original scalar fixture remains unchanged. A new independent Java oracle calls the genuine dev23 production classes and checks their class-load origins. Two fresh Java processes produce identical 34,976-record fixtures before native comparison. Debug and optimized Rust each match all 56,080 recorded values exactly. The expected file is immutable and never regenerated by the Rust verifier. Fixture metadata, Java/JAR/source hashes and the actual Rust compiler version are retained in `horizon-native-noise-foundation-v1.json`.

The corpus covers 296 vector pairs, six signed32 seeds including both endpoints, 17 coordinates per axis including negative integral/chunk boundaries and signed zero, all Perlin interpolation modes, and four frequency/octave/lacunarity/gain configurations. Perlin's stored seed and ignored compute-time seed are explicitly compared with two different compute-time seeds. Simplex's compute-time seed and Java wrapping additions are preserved. It is a finite numerical corpus, not proof for every floating-point or parameter input. Constructors reject octave counts outside 0..32.

Routine Perlin drafting used the authorized DeepSeek Delegator plugin, job `ee714237169545cd96700401b3d9f891`, model `deepseek-flash`, session `TerraForged-26.2`, estimated cost USD0.0028548. The first submission was rejected before dispatch because its output cap exceeded 4096; the corrected bounded submission returned this job. The returned draft had invalid JSON in its notes and invented interpolation helper names. Codex extracted the source as data, replaced those names with the actual Java LINEAR/Hermite/quintic mapping, reviewed operation order/wrapping and independently validated the result. No commands or tests supplied by the worker were executed. Simplex, fixture capture, integration and final verification were implemented locally.

The current production Java source is unchanged. Native source and fixtures remain outside the Java JARs and prepared `.hmod`. The complete composed-noise graph, default `MULTI_IMPROVED` continent system, rivers, erosion, filtered tiles, density/surfaces/caves/decoration and native client/save acceptance remain the next stages in `infinite-native-milestone.md`. Passing these small modules is not a completed Horizon port.
