# Independent default-kernel reference corpus

The first full Java kernel reference is now frozen under `horizon/tests/fixtures/kernel-v1`. It was produced without native output by the exact dev23 Fabric JAR, matching preset pack and a separate test companion. Production classes/fields are not patched to manufacture expected results.

The corpus binds the actual encoded preset and all26 registered custom noise definitions. It captures every public Cell field with raw float bits, signed integral coordinates, boolean erosion mask and stable terrain/biome names. The schema has24 fields. Stage points record terrain, rivers, climate enabled and climate disabled; complete final tiles include the real production generator's erosion, smoothing, steepness, beach/correction order and full backing halos.

Six long seed cases cover0, -1, both signed32 endpoints,8675309 and that seed plus2^32. The header records original long and narrowed kernel seed separately. The high32bit pair has identical cell-body hashes, confirming the actual narrowing rather than inventing distinct native terrain for the same kernel seed. Each case includes negative/chunk/tile-boundary points and tiles(-1,-1)/(0,0), using the actual size128 interior and16-block border at this preset configuration.

Each capture set contains310,104 cell records. Two fresh owned generator contexts produce identical compressed bytes for each case, giving620,208 recorded observations in one process. A second independent production JVM produces the same input/capture hashes. The Python archive verifier independently decompresses and checks field types, finite floats, boolean values, stage names, complete tile counts, seed narrowing, explicit completion/count markers and absence of trailing/truncated data before preserving the six reference files. It never creates expected values from Rust.

The binary format is Java DataOutput big endian, inside gzip. The string fields use DataOutput UTF; v1 schema/terrain/enum strings are ASCII and the reader explicitly rejects unsupported encodings. Header: magic string, long world seed, int kernel seed, field count and name/type pairs. Each cell has a stage string, worldX/worldZ ints and typed fields. `tile-layout` records identify each complete backing, and a final `complete` marker carries the cell count. Original compressed bytes, complete body hashes, field layout, actual terrain/biome counts and the two source report hashes are retained in `docs/validation/horizon-kernel-java-oracle-v1.json`.

This establishes an independent reference, not a native kernel pass. Intermediate individual filter snapshots, all landscapes and preset extremes are not captured. Rust still needs the composed graphs, continents, rivers, full filtered tiles and matching native density/biome/surface/cave/decoration pipeline. The finite prepared bridge remains separate.
