# Issues and blockers reviewed on 2026-11-07

The Horizon port remains experimental and is not yet qualified for modpacks.
This review checks current GitHub state and retained local evidence. It does
not represent a fresh run of the entire Java or native acceptance matrix.

## Unresolved issues

1. **Engine CI scheduling recovered; required checks are running.** Checks for engine PRs
   [8](https://github.com/TheApple05/horizon/pull/8) and
   [9](https://github.com/TheApple05/horizon/pull/9) were stuck queued. The latest
   heads of PRs [10](https://github.com/TheApple05/horizon/pull/10) and
   [11](https://github.com/TheApple05/horizon/pull/11) had no workflow runs.
   The Actions API reported enabled workflows and `SELF_HOSTED_CI=off`, but
   manual dispatch returned HTTP 422, "Actions has been disabled for this
   repository." Reapplying the API setting did not help. The signed-in Actions
   page exposed a separate disabled-fork banner. Re-enabling workflows there
   produced "Actions Enabled." Fresh exact-head runs now have real `verify`
   and `launcher` jobs in progress:
   [8](https://github.com/TheApple05/horizon/actions/runs/42420151716),
   [9](https://github.com/TheApple05/horizon/actions/runs/42420154244),
   [10](https://github.com/TheApple05/horizon/actions/runs/42420158959),
   [11](https://github.com/TheApple05/horizon/actions/runs/42420166166).
   The two obsolete zero-job runs were cancelled once. Scheduling is fixed;
   required checks must still pass before merging. Required check contexts
   and branch protections have not been weakened; protected merges remain open.

2. **The broad renderer suite did not complete.** Its isolated Windows test
   process was terminated after exceeding 20 minutes. This is not a passing
   renderer suite, and the underlying cause has not been established. Separate
   checks passed six renderer biome tests and 581 core/world tests, with seven
   core/world tests ignored. The full renderer/GPU gate remains incomplete.

3. **The all-17 client/save run is unfinished.** Six classic-biome screenshots
   exist, but there is no final `horizon-native-classic-ui-v1.json` report.
   The frozen-marsh teleport was recorded at 01:28:01.162 UTC on November 5;
   the last block query was at 01:28:07.544 UTC. Eight status samples span only
   4.900 seconds, while frames and client ticks advanced. This does not establish
   a frozen-marsh loading stall. The reported zero chunk/streaming counters,
   including the misleadingly named `server.chunks`, describe the client rather
   than authoritative integrated-server generation. The target was not yet
   loaded when observation ended; no panic or shutdown was retained. The test
   old v5 processes are no longer running. Several earlier locations
   took minutes between teleport and capture while compilation also ran; these
   observations are not controlled performance measurements. The next debugging
   step is now running against final-v1: a fresh-world run with frozen marsh as the first teleport, the full
   420-second visibility deadline and sparse `horizon-ctl memory` samples of
   actual integrated-server columns and generation stages, followed by all 17
   locations, complete save/reopen checks and image review. At this report's
   publication it is preparing the isolated resource copy, with no completed
   client or save checks. Its in-progress JSON is not passing evidence.

4. **The staged-gameplay lint fix needs remote verification.**
   Expanded native CI exposed five pre-existing nested-condition style errors
   after AST staging removed ordinary comments. PR 11 collapses those conditions
   while retaining evaluation order and comments. Strict local gameplay-library
   Clippy passes, and the newer full staged client build completed successfully
   in 10 minutes 46 seconds.
   The newer pin `b33109ad199d2e149c80c8dc7d97f879c4f4ffec`, formatting,
   client metadata checks and incremental UI/save diagnostics were published
   in native PR 3 by commit `0d991bc`. The older failed UI lint job has not yet been
   superseded by a verified passing remote run of that fix.

5. **One environment baseline test remains red.** The host Python suite ran
   663 tests, with 14 skips and one previously reproduced missing-WSL-`/bin/bash`
   failure in `test_server_panels`. It is not attributed to the port, and the
   suite is not recorded as wholly passing.

## Remaining acceptance work

Native source-carver configuration still inherits the engine's vanilla settings
rather than the Java port's complete preset configuration. Independent Java
whole-feature block parity, mixed structures/decoration, standard launcher
installation, controlled native performance and native mod combinations remain
unfinished. These are explicit implementation or acceptance gaps, rather than
checks silently counted as passing. Complete original TerraForged fidelity has
not been established.

Independent records pass all 17 native variants in live queries and stored
generated quarts in two fresh processes, client metadata registration and pack
priority, actual pillar/marsh placement, and the recorded ownership/lifecycle
checks. These passes do not close the unresolved client/GPU/performance gates.

double-precision comparisons, Windows Java-probe line endings, offline CI
dependency ordering and native injection types/scopes. Their failed attempts
remain in the project evidence instead of being overwritten.

The Java 26.2 Fabric/NeoForge work is separate. The current Java README identifies
dev24 as a fresh build with narrower checks and dev23 as the broader recorded
client/modpack/performance qualification. That broad matrix was not rerun for
this review, and arbitrary modpack compatibility or complete classic parity is
not claimed.

## Reporting requirement and review

Repeated failures, unexpectedly long stalls and missing required evidence must
be surfaced promptly, with their impact, attempted fixes and next debugging
step. They must not wait until another feature milestone to be reported.

This report was checked against current GitHub workflow state, completed log
endings, report JSON statuses, screenshot counts and process state. A separate
draft review was cross-checked against the underlying evidence. The report distinguishes stopped/interrupted tests,
unverified fixes, environment failures, remaining work and completed checks.
